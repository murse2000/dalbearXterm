# dalbearXterm 0.5.2

- 명령 라이브러리 창의 제목이 잘리고 가로 스크롤이 생기던 문제를 고쳤습니다. 제목 영역의 잘못된 여백을 바로잡아 폼과 목록이 창 안에 정확히 들어옵니다.
- 다크 테마에서 선택한 명령의 글자가 배경과 겹쳐 읽기 어렵던 문제를 고쳤습니다. 선택 행은 테마 공통 선택색을 쓰고, 글자 대비를 4.5 이상으로 유지합니다.
- 명령 목록의 버튼 순서를 ‘편집 → 삭제’로 정리하고, ‘저장된 명령’ 제목의 어색한 배경 띠를 없앴습니다.
- 화면 폭·넘침·선택 행 대비를 두 테마에서 실측하는 검사를 추가했습니다. 이후 변경이 레이아웃을 깨면 시험이 먼저 알려 줍니다.

저장된 세션·테마·명령·홈 화면 설정을 유지합니다. 다운로드와 설치·재시작은 각각 사용자 동의 후에만 진행합니다.
