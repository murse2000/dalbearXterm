# dalbearXterm 0.5.0

- 명령 팔레트(Ctrl+Shift+P)와 ‘명령 라이브러리 관리’를 추가했습니다. 자주 쓰는 시리얼·SSH 명령을 이름·모드(TEXT/HEX)·줄 끝과 함께 저장하고, 활성 세션에 즉시 전송할 수 있습니다.
- 명령 라이브러리는 `settings.json` 안 `commands`에 저장되며 비밀번호·개인키 내용은 포함하지 않습니다. 같은 필드로 다른 PC의 설정을 가져올 수 있습니다.
- 메인 메뉴 ‘터미널 → 명령 팔레트’(Ctrl+Shift+P)로도 열 수 있고, 팔레트 안에서 ‘명령 라이브러리 관리’로 이동해 새 명령을 만들거나 편집·삭제할 수 있습니다.
- 명령 팔레트에서 위/아래 화살표로 항목을 고르고 Enter로 실행합니다. 더블 클릭도 같은 동작입니다.

저장된 세션·테마·명령·홈 화면 설정을 유지합니다. 다운로드와 설치·재시작은 각각 사용자 동의 후에만 진행합니다.
