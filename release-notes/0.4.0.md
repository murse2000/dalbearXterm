# dalbearXterm 0.4.0

- 홈 화면 오른쪽 위에 ‘홈 꾸미기’를 추가했습니다. 배경색과 중앙 로고를 미리 본 뒤 저장할 수 있습니다. 취소하거나 닫으면 적용하지 않습니다.
- 선택한 배경색에 맞춰 홈 안내 글자색을 자동 조정합니다. 터미널·세션 패널·앱 아이콘·상단 로고는 유지합니다.
- PNG·JPG·WebP 이미지(최대 5MB)를 로고로 사용할 수 있습니다. 비율을 유지한 작은 PNG로 저장하므로 원본 파일을 옮기거나 앱을 다시 실행해도 표시됩니다.
- ‘테마 기본색’과 ‘기본 로고’로 각각 복원할 수 있습니다. 기본 배경색은 일반·다크 테마를 따르고, 사용자 배경색은 테마를 바꿔도 유지됩니다.

저장된 세션과 테마 설정을 유지합니다. 다운로드와 설치·재시작은 각각 사용자 동의 후에만 진행합니다.
