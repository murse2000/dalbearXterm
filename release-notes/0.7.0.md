# dalbearXterm 0.7.0

- 보기 → 터미널 설정(Ctrl+,)과 상단 ‘터미널 설정’ 버튼을 추가했습니다. 글꼴, 글자 크기(8–32), 줄 간격(1.0–2.0), 커서 모양(블록·밑줄·막대), 커서 깜박임, 스크롤백 줄 수(100–200000)를 바꿀 수 있습니다.
- 설정 창에는 새 설정이 적용된 미리 보기 줄이 표시됩니다. 취소하거나 창을 닫으면 편집 전 값으로 되돌아갑니다.
- 키워드 하이라이트를 추가했습니다. 키워드와 색상을 등록하면 수신 화면에서 해당 글자색이 바뀝니다. 대소문자 구분과 정규식을 지원하며, 규칙마다 사용 여부를 켜고 끌 수 있습니다.
- 하이라이트는 화면 표시에만 적용됩니다. 원본 `.bin` 로그, 텍스트 로그, 복사한 내용은 바뀌지 않습니다. 화면에 보이는 줄을 기준으로 적용되고, 스크롤하면 그 위치의 줄에도 적용됩니다.
- 여러 규칙이 같은 글자에 겹치면 먼저 등록한 규칙의 색을 사용합니다.

저장된 세션·테마·명령·홈 화면 설정을 유지하며 새 설정은 같은 `settings.json`에 저장됩니다. 다운로드와 설치·재시작은 각각 사용자 동의 후에만 진행합니다.
