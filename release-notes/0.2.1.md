# dalbearXterm 0.2.1

- 터미널 중심의 고밀도 UI로 변경했습니다. 상단 도구 모음을 72px에서 32px의 한 줄로 줄였습니다.
- 첫 터미널을 열면 왼쪽 패널을 26px 레일로 접습니다. 세션 버튼으로 다시 펼칠 수 있고, SFTP·포트는 요청할 때 표시합니다. 펼친 패널 폭도 267px에서 196px로 줄였습니다.
- SSH·로컬 터미널의 TEXT/HEX 송신줄은 ‘송신’ 버튼으로 표시합니다. 시리얼 송신줄은 기본 표시하고, DTR/RTS/BREAK는 ‘신호’ 버튼으로 펼칩니다.
- 정상 연결의 중복 상태줄을 숨겼습니다. 오류와 연결 종료 안내는 유지합니다.
- 같은 1464×857px 화면, 같은 13px 글자 크기에서 터미널 영역이 1195×641px에서 1436×754px로 약 41% 늘고 표시 행이 37행에서 44행으로 늘었습니다.
- 1024×640px 분할 화면의 도구 배치와 패널·송신줄 토글, SSH·SFTP·PowerShell·로그·수신 SHA-256을 검증했습니다.

기존처럼 다운로드와 설치·재시작에 각각 동의해야 업데이트합니다. 저장된 세션과 설정을 유지합니다.
