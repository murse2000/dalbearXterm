# dalbearXterm 0.2.2

- 업데이트 내역의 줄바꿈이 사라져 제목·문단·변경 항목이 붙어 보이던 문제를 수정했습니다.
- 업데이트 창에 한글 글꼴을 적용해 글줄이 겹치지 않고 읽을 수 있도록 했습니다.
- 내역 표시 영역을 넓혔습니다. 창 크기를 조절하면 내역 영역도 함께 늘어나며, 긴 내역은 스크롤해서 읽을 수 있습니다.

다운로드와 설치·재시작은 각각 사용자 동의 후에만 진행합니다. 저장된 세션과 설정은 유지합니다.

이 수정은 0.2.2 적용 후 표시하는 업데이트 창부터 반영됩니다. 이전 버전에서 이 내역이 붙어 보이면 GitHub 릴리즈 페이지에서 확인할 수 있습니다.
