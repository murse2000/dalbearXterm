# dalbearXterm 0.3.0

- 상단 테마 선택과 보기 → 테마 메뉴에 일반·다크 테마를 추가했습니다. 선택은 저장되며 앱을 다시 실행해도 유지됩니다.
- 세션·탭·SFTP 파일 목록·연결 설정·검색·송신줄·시리얼 신호·HEX·상태 및 오류 안내에 같은 테마를 적용합니다.
- 이미 열린 터미널과 분할 화면의 기본 글자색·커서·선택 영역·ANSI 팔레트를 함께 변경합니다. 연결과 출력 이력은 유지하고, 새 터미널에도 선택한 테마를 적용합니다.
- Windows 메뉴와 앱의 업데이트·SSH 지문 확인·설치 동의·오류 안내 창도 같은 배경색과 글자색을 사용합니다. 지원하는 Windows에서는 제목 표시줄도 함께 변경합니다.

일반 테마는 밝은 UI와 검은 터미널, 다크 테마는 어두운 UI와 남색 계열의 터미널을 사용합니다. Windows 공용 파일 선택창과 일부 운영체제 장식은 Windows 테마·버전을 따릅니다.

다운로드와 설치·재시작은 각각 사용자 동의 후에만 진행합니다. 저장된 세션과 설정을 유지합니다.
