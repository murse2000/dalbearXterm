# dalbearXterm 0.2.0

- 달·곰·터미널을 조합한 전용 아이콘을 실행 파일, 작업 표시줄, 설치 파일, 앱 화면에 적용했습니다.
- Windows 네이티브 창과 WebView2를 사용해 시작 속도를 개선했습니다.
- GitHub Releases에서 새 안정 버전을 확인합니다. 다운로드 동의 전에는 업데이트 패키지를 받지 않습니다.
- 다운로드·SHA-256 검사 후 설치와 재시작에 별도로 동의해야 적용합니다. ‘나중에’, 창 닫기, 일반 재실행은 업데이트를 적용하지 않습니다.
- 업데이트할 때 시리얼·SSH·로컬 셸·로그·SFTP 전송을 정리한 뒤 재시작합니다. 저장된 세션은 유지됩니다.
- 시리얼·SSH·SFTP, TEXT/HEX 전송, 수신 로그, 로컬 PowerShell, 터미널 분할 화면을 제공합니다.

처음 설치할 때는 `DalbearXterm-win-Setup.exe`, 설치 없이 사용할 때는 `DalbearXterm-win-Portable.zip`을 받으세요. 기존 0.1.0 사용자는 이번 배포본으로 한 번 전환하면 이후 앱 내 업데이트를 사용할 수 있습니다.
