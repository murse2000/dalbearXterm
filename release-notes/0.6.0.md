# dalbearXterm 0.6.0

- 탭을 드래그해 순서를 바꿀 수 있습니다. 드롭 위치가 대상 탭의 왼쪽 절반이면 그 앞, 오른쪽 절반이면 그 뒤로 이동합니다.
- 탭 이름을 세션별로 바꿀 수 있습니다. 탭 이름을 더블클릭하거나 탭에서 F2를 누른 뒤 입력하고 Enter로 확정, Escape로 취소합니다. 저장된 세션 이름은 바뀌지 않습니다.
- 키보드로도 탭을 옮길 수 있습니다. 탭에 포커스를 두고 Alt+←/Alt+→를 누르면 한 칸씩 이동합니다.
- 출력 검색에 대소문자 구분(`Aa`), 정규식(`.*`), 이전/다음 이동(↑/↓), 결과 개수(`3/12`)를 추가했습니다. Enter는 다음, Shift+Enter는 이전 결과로 이동하고 Escape는 강조를 지웁니다. 일치 항목은 터미널과 스크롤 막대에 함께 강조됩니다.
- 송신줄에서 ↑/↓로 이전에 보낸 내용을 다시 불러옵니다. 입력을 고치면 기록 탐색이 초기화되고, 같은 내용을 연속 전송하면 기록은 하나만 남습니다. 명령 팔레트로 실행한 명령도 같은 기록에 쌓입니다.
- 테마를 바꾸면 검색 강조색도 새 테마에 맞춰 다시 그립니다.

저장된 세션·테마·명령·홈 화면 설정을 유지합니다. 재연결 후 이전 송신 내용을 자동으로 다시 보내지 않습니다. 다운로드와 설치·재시작은 각각 사용자 동의 후에만 진행합니다.
